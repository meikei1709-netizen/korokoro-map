👀 閲覧専用モードです（記録・写真は変更できません）
※記録や写真は、まずこの端末のブラウザに保存されます。別のブラウザ・スマホ・家族とも見られるようにするには「☁ 共有・同期」を設定してください（設定するまで、外部には送信しません）。ときどき「記録を書き出す」（写真も一緒に書き出されます）でバックアップもできます。

☁ 共有・同期

公開したサイトのURL
いまはパソコン内のファイルとして開いています。GitHub Pages などに公開したURLを入れると、家族に送れるリンクが作られます。
スマホや家族と、記録と写真を共有できます。無料の Firebase でデータベースを1つ用意し、そのURLを下に入れてください（手順は README にあります）。「共有を作る」を押すと、いまの記録と写真がアップロードされます。
共有リンクをもらっている場合は、そのリンクを開くだけでつながります。
編集もできるリンク（自分・家族用）
閲覧専用リンク
リンクを知っている人は、誰でも記録や写真を見られます（編集リンクなら変更もできます）。家族以外には送らないでください。「閲覧専用」は、うっかり編集を防ぐためのものです。
